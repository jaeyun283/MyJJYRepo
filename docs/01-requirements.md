# 1. 요구사항과 참고자료 대응표

## 자료 수신·검토 현황
페이지는 PDF 파일의 1부터 시작하는 실제 페이지 번호다. 이미지 파일명은 대화에 제공되지 않아 첨부 순서 I1~I3로 식별한다.

| 자료 | 검토 범위 | 확인 방법 |
|---|---|---|
| 수행계획서.pdf | 1~20쪽 전체 | 전체 텍스트 및 전 페이지 렌더 확인; 도식 7·8·13쪽 확대 확인 |
| 발표자료.pdf | 1~29쪽 전체, 부록 19~29쪽 | 전체 텍스트 및 전 페이지 렌더 확인 |
| I1: 첫 번째 예시 이미지 | 내 프로젝트, 경험 그래프 | 대화 내 이미지 직접 확인 |
| I2: 두 번째 예시 이미지 | 관심사·패턴, 포트폴리오 유형 선택 | 대화 내 이미지 직접 확인 |
| I3: 세 번째 예시 이미지 | 프로젝트 포트폴리오 초안 편집 | 대화 내 이미지 직접 확인 |

앞선 문서는 잠정안이었다. 이번 대조 후 결정과 자료별 상세 기록은 [0단계 검토 기록](00-reference-review.md)에 정리했다. 기술 구현 세부 스키마와 경로는 개발 설계이며 PDF가 직접 정한 항목으로 주장하지 않는다.

| R10 | 실데이터 UI·실시간 지표 | DB 집계·검색·Realtime 재조회 | 저장/삭제 결과가 지표와 검색에 반영 | 사용자 실제 동작 지시; 발표 9쪽 시안은 가상 데이터 |
| R11 | 사용자 격리와 비밀 보호 | RLS·Storage 정책·서버 소유권 확인 | 다른 계정의 UUID로도 자료 접근 불가 | 수행 7·10·14쪽; 사용자 RLS·서버 검증 지시 |
| R12 | AI 전송 동의, 자동 덮어쓰기 금지 | 전송 미리보기·동의 기록·검토 단계 | 동의 없으면 API 호출 없음, 제안 채택만 별도 저장 | 수행 8·11~12·14쪽; 발표 10·28쪽; 사용자 전송 동의 강화 |
| R13 | 명시적인 데모만 | 격리된 데모 저장소·배너 | 실제 계정에 샘플 생성 없음, 데모에서 외부 토큰 사용 없음 | 발표 9·21~29쪽 가상 데이터 표기; 사용자 데모 분리 지시 |
| R14 | 범위 제외 | 코치 평가·대학 추천·합격예측·점수화 미구현 | 메뉴/스키마/API에 제외 기능 없음 | 수행 15쪽; 발표 11쪽; I2·I3 코치 메뉴는 사용자 지시로 제외 |

학생의 역량이나 합격 가능성을 수치 평가하지 않는다. 대시보드 숫자는 자료·경험·검토 대기 건수 등 작업 현황이다. 추출·구조화 실패는 원본을 삭제하지 않고 재시도 또는 직접 경험 연결을 제공한다.
