# 2. 화면 목록과 사용자 흐름

예시 이미지 3장을 직접 확인해 밝은 흰색·연한 라벤더 배경, 보라색 강조, 짙은 남색 제목, 둥근 카드와 얇은 경계선, 고정 좌측 메뉴·상단 검색을 시각 기준으로 채택한다. 어두운 배경은 경험 그래프 영역에 한정한다. 발표 슬라이드의 짙은 배경은 서비스 전체 테마로 옮기지 않는다. 이미지의 문서 편집 도구 오버레이·스크롤바·외부 페이지 여백은 앱 UI에서 제외한다.
핵심 좌측 메뉴는 **내 프로젝트 / 나의 배움 정리 / 포트폴리오 만들기**다. AI 상담·설정을 추가하고 코치 진입함/코치 알림은 제거한다. 대시보드·자료함·보완은 내 프로젝트의 요약·하위 화면으로 묶고 경험 그래프는 나의 배움 정리에 배치한다. 아래 경로는 구현 후보이며 메뉴 이름과 구별한다.

| 화면/경로 후보 | 주요 행동 | 데이터·상태 |
|---|---|---|
| 로그인 /login | Supabase 로그인·로그아웃 | 세션 만료/가입 오류 |
| 내 프로젝트 요약 /dashboard | 최근 활동, 검토 대기, 보완 항목 열기 | 저장된 건수·최근 수정·Realtime 재조회 |
| 자료함 /materials | 파일 업로드, 기존 텍스트 붙여넣기, 검색, Drive 선택 | 업로드 진행·검증 실패·분석 미동의·추출 상태 |
| 자료 상세 /materials/[id] | 원본 열기, 버전/출처 확인, 분석 대상 선택 | private 파일, 추출 조각·서명 URL |
| AI 전송 확인 /analysis/new | 대상·추출 내용·수신자 Gemini·목적 확인 후 동의 | 동의 없이 전송 불가, 변경 시 재동의 |
| 경험 제안 검토 /reviews/[id] | 역할·과정·결과 수정/거절/확정, 근거 확인 | AI 제안/학생 확정 명확히 구분 |
| 경험 목록·상세 /experiences/[id] | 검색·편집·근거 연결, 보완 | 확정 버전, 연결 자료, 부족한 근거 설명 |
| 나의 배움 정리: 경험 그래프 /learning/graph | 경험-프로젝트-근거 노드 선택 | 권한 있는 DB 그래프, 빈 상태, 목록 대안 |
| 기록 보완 /gaps | 기존 자료 추가·근거 연결·짧은 설명 | 필요한 이유 표시, 필수 정형 일지 없음 |
| 목적별 활용 /uses/new | 발표/자기소개/활동 정리 등 목적과 경험 선택 | 학생 선택, 추천 대학 DB 없음 |
| AI 상담 /consultation | 문맥 선택·전송 확인·질문·제안 검토 | 키 미설정/오류, 근거 링크, 확정정보 덮어쓰기 없음 |
| 포트폴리오 /portfolios/[id] | 섹션 편집·경험 배치·초안 생성·저장 | 저장 충돌, 근거, 미확정 AI 표시 |
| 설정 /settings | Drive 연결·해제, 동기화, 개인정보 삭제 | 연결 필요/만료/철회, 최근 실제 성공 시각 |

## 핵심 경로
1. 로그인 → 기존 자료 등록. 제목/설명은 가능한 범위에서 추출하고 선택적 수정만 제공한다.
2. 업로드 형식·크기 검사 → 원본 private 저장 → 텍스트 추출. 추출 실패는 상태와 원인을 표시한다.
3. 학생이 전송할 파일/버전/내용과 분석 목적을 확인 → 명시적 동의 → 실제 Gemini 호출.
4. AI가 역할·행동·과정·결과 후보와 근거 위치를 제안 → 학생이 원본과 대조해 수정/거절/확정.
5. 확정 경험과 원본 조각 연결 → 역할 또는 결과를 설명할 근거가 부족하면 이유와 보완 방법 표시.
6. 기존 자료 추가/짧은 설명으로 보완 → 목적에 맞는 경험 선택 → 포트폴리오 초안 → 학생 편집·저장.

## Drive 및 상담 경로
Drive 연결 → Picker에서 파일 선택 → 서버에서 사용자의 Google 권한 확인 → 가져오기 → 원본 버전 저장. 이후 변경 확인은 명시적 동기화 버튼부터 구현한다. 주기 동기화는 스케줄러와 재시도 검증 뒤 제공한다. 동기화가 새 내용을 가져와도 AI에 자동 전송하지 않는다.
상담은 선택 경험·근거의 전송 미리보기 → 동의 → 실제 응답 → 관련 근거 열기/제안 검토로 연결한다. 상담 답변을 사용자 확정 경험으로 자동 저장하지 않는다.

## 공통 상태 및 접근성
빈 상태는 실제 첫 자료 등록을 안내한다. 로딩·저장중·실패·재시도·연결 필요를 각각 표시한다. 실패 시 성공 토스트를 띄우지 않는다. 입력 중 편집을 유지하고 revision 충돌 시 재검토한다. 그래프에는 키보드 가능한 목록 대안을 둔다. 다른 사용자 자료는 존재 여부를 노출하지 않는다. 데모는 명시적 배너와 독립 데이터 저장소를 사용한다.

## 자료에 근거한 핵심 화면 구체화
| 화면 | 구성·행동 | 근거 |
|---|---|---|
| 내 프로젝트 | 좌측 프로젝트 목록/새 프로젝트, 중앙 선택 프로젝트·기간·수정·자료 관리/프로젝트 개요/진행 기록/성과 정리 탭·업로드·링크/메모, 우측 AI 보완 제안·7개 기록 상태 | 발표 21쪽, I1. 중앙 4탭은 I1에서 확인 |
| 나의 배움 정리: 경험 그래프 | 경험 그래프/관심사·패턴 탭, 프로젝트 필터, 경험·기록 노드·선택 연결 강조·줌, 우측 선택 경험·내 역할·연결 기록·보완 | 발표 23쪽, I1 |
| 나의 배움 정리: 관심사·패턴 | 반복 관심사 칩, 선택 관심사의 관련 경험 수, 관찰→문제 정리→개선안 등 실제 활동 패턴, 관련 프로젝트와 기록·AI 해석 수정·그래프로 이동 | 발표 24쪽, I2 |
| 포트폴리오 유형 선택 | 1 유형 선택→2 경험 선택→3 초안 편집 표시, 프로젝트 포트폴리오/대체서식 카드 | 발표 26쪽, I2 |
| 경험 선택 | 프로젝트별 기간·역할·문제·과정·결과·증빙·회고 태그, 복수 선택, 미확인 있어도 진행, 추천 순위 없음 | 발표 27쪽(첨부 이미지에 이 단계 없음) |
| 초안 편집 | 좌측 프로젝트 순서/위·아래 이동, 중앙 문제·내 역할과 과정·결과와 회고 편집, 우측 간결하게/역할 중심/선택 부분 다시 쓰기·참고 기록, 저장·미리보기 | 발표 28쪽, I3 |
| 출력 미리보기 | 프로젝트 중심 작성안과 활동명·기간·활동내용·기관 표의 대체서식, 증빙 준비 체크리스트 | 발표 29쪽(첨부 이미지에 출력 화면 없음) |

등록 링크는 출처로 저장하며 임의 URL을 서버가 자동 크롤링하지 않는다. AI 대상은 사용자가 확인한 텍스트·지원 추출 내용이다. 지원하지 않는 링크 추출은 원본 링크 열기와 기존 텍스트 붙여넣기를 제공한다.
관심사·패턴 AI 해석은 근거를 보여주고 수정/거절 가능하다. 그래프의 장식용 샘플 노드나 고정 경험 수를 실제 계정에 표시하지 않는다. 핵심 3단계에서 필요한 분석 전송 확인은 별도 확인 패널로 제공하되 기존 자료 재입력을 요구하지 않는다.
대체서식은 발표의 서울대 2027 참고 작성안으로 표시한다. 발표에 적힌 활동내용 100자 이내·최대 10개 활동은 공식 원본 대조 전에는 제출 요건 확정값으로 표시하지 않는다. 템플릿 선택과 목적 설정은 분리해 진로 미정 학생도 시작할 수 있다.
모바일에서는 좌측 메뉴를 접고 프로젝트 목록→내용→보완/근거를 순서대로 접근할 수 있게 한다. 그래프 대신 근거 목록도 제공하고 편집·순서 이동 버튼을 터치/키보드로 사용할 수 있게 한다.
