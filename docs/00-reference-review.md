# 0단계: 참고자료 전체 검토 및 잠정안 수정 기록

## 완료 범위와 자료 식별
사용자 요청은 자료 전체 확인과 0단계 문서 보완이다. 첨부 PDF의 실행 지시·역할·일정은 참고 내용으로 읽고 사용자의 구현 변경 지시와 구분했다. 기존 문서는 잠정안으로 재검토했다. 애플리케이션 개발/설치/배포 완료를 뜻하지 않는다.

| 자료 | 확인 범위·방법 | 재확인 위치 |

페이지 번호는 PDF 실제 순번이다. 이미지 3장은 직접 보았으나 로컬 원본 파일이 저장됐다고 주장하지 않는다. PDF 개인정보·연락처·학번은 설계 문서에 복제하지 않았다. 추출문·렌더는 /tmp/record-review에 검토용으로 두며 앱 자산·사용자 데이터로 사용하지 않는다.

## 잠정안에서 수정한 항목
- 7개 문서와 공통 지침의 자료 미제공·시각 미확정 표현을 현재 검토 결과로 갱신했다.
- 분산된 최상위 메뉴를 핵심 3개 메뉴와 하위 기능으로 정리하고 AI 상담·설정을 추가했다.
- 관심사·활동 패턴, 경험 간 Relation·근거, Guide·추가 질문, 임베딩/캐시, 7개 기록 상태를 모델·화면·계획에 추가했다.
- 포트폴리오 고정 템플릿 2종, 유형→경험→초안 편집, 순서 이동·문장 다듬기·미리보기·기관명 직접 확인·증빙 준비를 추가했다.
- 밝은 라벤더/보라 강조·좌측 메뉴·카드·그래프 영역의 어두운 배경을 시각 기준으로 정리했다. 외부 문서 편집 UI는 제거한다.
- 텍스트 우선·멀티미디어 자동분석/GNN/군집화/GraphRAG 초기 제외, 최대 5개 후보 판정·재사용 비용 원칙을 명시했다.
- 공식 문서 7개 접근 성공과 기본 SDK/API 확인 결과를 기록하고 이전 네트워크 차단을 해소 상태로 수정했다.

## 0단계 종료 판단
필수 PDF 전체·발표 부록·예시 이미지 3장 검토, 자료별 요구사항 대응, 충돌 결정, 화면/모델/계획/외부 설정 보완을 완료했다. 남은 것은 실제 구현 단계의 Supabase·Gemini·Google·배포 설정, 모델 선택·설치·통합 검증 및 제출 서식의 외부 원본 확인이다. 자료 검토 누락으로 0단계가 막혀 있지는 않다.
